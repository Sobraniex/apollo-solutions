# Apollo Solutions

Firm site for the studio behind the apps. Hermes Dental is the first product, at `/hermes/`.

```
apollo-solutions/website/
├── index.html      # firm site
├── hermes/         # Hermes Dental product site
└── blog/
```

The actual Hermes app still lives in `hermes-dental-clone/app`.

## Run locally

```bash
cd /Users/julijan/apollo-solutions/website
python3 -m http.server 8100
```

- Firm: http://localhost:8100
- Hermes: http://localhost:8100/hermes/

## What this is

Apollo Solutions is the studio. It does not take every project. It picks problems the market overcharges for — expensive apps, expensive subscriptions — builds the tool, and helps install it. No subscription for now.

Four product slots. Hermes Dental is live and links to its own site. The other three stay empty until the next problem is chosen.

Notes (blog) live in `website/blog/`.
